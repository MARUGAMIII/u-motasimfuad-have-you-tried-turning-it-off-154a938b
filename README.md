One funny line a hopeless tech support agent says to a desperate customer, written for make.fun's "Have You Tried Turning It Off?" bounty: "I've escalated your case to our senior team. It's just me again, but I've put on a different headset, so it feels official." (123 characters, ASCII only.) The joke lands on the agent's cheerful uselessness — the "senior team" is the same agent again, in a different headset — never on the customer, and it skips the tired "turn it off and on again" cliche entirely.

The entry program writes that single line to `/output/entry.txt` — one line, 123 characters, ASCII only — and reads it back to verify the length and that no non-ASCII character (and no em dash) is present.

## Run it

```sh
python3 main.py
```
